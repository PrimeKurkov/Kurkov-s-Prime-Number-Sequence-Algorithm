# Kurkov-s-Prime-Number-Sequence-Algorithm
В репозитории продемонстрировано, что при использовании усеченной матрицы Якоби JN размера N = ⌈n/2⌉, алгоритм Китамасы совместно с операцией масштабирования (уравнение 5) безошибочно генерирует последовательность pn с абсолютной точностью, ограниченной исклю- чительно выбранной разрядностью (dps) вычислений. https://orcid.org/0009-0009-0756-1744
