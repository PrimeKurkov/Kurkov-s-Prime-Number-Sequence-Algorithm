## 📌 Аннотация проекта

Данный проект реализует строго детерминированный спектральный подход к исследованию структуры натурального ряда. Мультипликативная природа последовательности простых чисел $\{p_n\}_{n=1}^\infty$ рассматривается не через вероятностные эвристики, а как дискретный след обращения резольвенты оператора на компактном многообразии расслоения Хопфа $S^3 \to S^2$.

### Ключевые математические результаты:

1. **Оператор обращения степенных рядов:** Последовательность простых чисел $\{p_n\}$ взаимно-однозначно изоморфна целочисленным макро-моментам $\{c_n\}$ через оператор инверсии $P(x) = \frac{C(x)}{1 + C(x)}$, эквивалентный диофантовой треугольной свертке в кольце $\mathbb{Z}$:
   $$p_n = c_n - \sum_{k=1}^{n-1} p_k \cdot c_{n-k}, \quad p_1 = c_1 = 2$$

2. **J-дроби Стилтьеса и комплексная матрица Якоби:** Производящая функция моментов $C(x)$ разлагается в непрерывную J-дробь трехдиагональной матрицы Якоби $J$. Первые 7 слоев матрицы ($k = 0 \dots 6$) выражаются **точными рациональными числами**:
   $$a_k = r_k / \rho, \quad b_k^2 = s_k / \rho^2$$
   $$r = \{2, \; 5/3, \; -7/6, \; 3/2, \; -1, \; -3/2, \; \mathbf{61/74}\}$$
   $$s = \{3, \; -4/9, \; 9/4, \; -4, \; 1/3, \; -37/12, \; \mathbf{707/1369}\}$$

3. **Аналитическое устранение полюса сингулярности:** Радиус сходимости ряда моментов $C(x)$ равен $R_C = 1/\rho \approx 0.2838$, однако в точке $x = 1/\rho$ полюс аналитически аннигилируется числителем ($\lim_{x \to 1/\rho} P(x) = 1$). Истинный радиус сходимости ряда простых чисел равен **$R_P = 1$**, что строго согласуется с теоремой Коши–Адамара и законом распределения простых чисел $p_n \sim n \ln n$.

4. **Теорема о 3-периодичности четности:** Индуктивно доказано, что четность моментов строго периодична с периодом 3:
   $$c_n \equiv 0 \pmod 2 \iff n \equiv 1 \pmod 3, \quad c_n \equiv 1 \pmod 2 \iff n \equiv 0, 2 \pmod 3$$

5. **Закон спектрального усечения Гаусса–Якоби:** Для точного вычисления $p_n$ порядок матрицы $N$ обязан удовлетворять квадратурной теореме $N \ge \lceil (n+2)/2 \rceil$.

### 1. Вычислительный модуль: Алгоритм Zero-Spectral (`Code.py`)

Модуль вычисляет простые числа $p_n$ через устойчивую линейную рекурренту характеристического многочлена матрицы Якоби $\chi_{J_N}(\lambda)$ без дорогостоящей операции диагонализации матриц $\mathcal{O}(N^3)$, после чего выполняет точную деконволюцию в кольце целых чисел $\mathbb{Z}$:

```bash
python Code.py
```

### 2. Графический модуль: Фазовое погружение на торе Хопфа (`Visuality.py`)

Скрипт генерирует комплексную 2D-визуализацию спектрального разложения оператора $\hat{\mathcal{O}}$ для первых 2500 простых чисел:

```bash
python Visuality.py
```

**Что отображает график:**
* **Центр полотна:** Ядро матрицы моментов $J$ размера $7 \times 7$ (точные рациональные коэффициенты $r_k, s_k$).
* **Белые пунктирные лучи:** Четыре предельных топологических нуля фазовой плотности $A(\theta)$:
  $$\theta_1 \approx 48.929140^\circ, \quad \theta_2 \approx 153.803679^\circ, \quad \theta_3 \approx 206.196321^\circ, \quad \theta_4 \approx 311.070860^\circ$$
* **Бирюзовая непрерывная кривая:** Непрерывный резонансный геодезический поток с фазой:
  $$\Phi(t) = \rho t + Z_\rho + 50 \sum_{m=0}^3 \beta_m \sin\bigl((m+1)\rho t\bigr)$$
* **Цветные узлы:** Точки локализации простых чисел $p_n$ как стоячих интерференционных волн.
